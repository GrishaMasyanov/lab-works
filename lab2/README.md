# Лабораторная работа №2

## Описание проекта

Данный проект представляет собой реализацию иерархии классов для сотрудников компании. Работа выполнена в рамках изучения принципов объектно-ориентированного программирования (ООП) на языке Java.

В проекте продемонстрированы основные механизмы ООП: абстракция, инкапсуляция, наследование и полиморфизм.

---

## Иерархия классов

Проект включает в себя три уровня классов:

1. **Employee** (Абстрактный класс) — базовый уровень, содержащий общие характеристики сотрудника:
   - имя;
   - возраст;
   - заработная плата.

2. **OfficeEmployee** (Абстрактный класс) — промежуточный уровень, добавляющий характеристики офисных работников:
   - отдел;
   - стаж работы;
   - график работы.

3. **Конечные классы:**
   - **Administrator** (Администратор)
   - **Programmer** (Программист)
   - **Manager** (Менеджер)

---

## Реализованные критерии ООП

В работе продемонстрированы основные принципы объектно-ориентированного программирования.

### Абстракция

Используются абстрактные классы:

- `Employee`
- `OfficeEmployee`

В них определены общие поля и абстрактные методы:

```java
work();
showInfo();
```

которые реализуются в дочерних классах.

### Инкапсуляция

Все поля классов объявлены с модификатором доступа `private`.

Доступ к данным осуществляется через:

- геттеры (`get...()`);
- сеттеры (`set...()`).

### Наследование

Создана двухуровневая цепочка наследования:

```text
Employee
    ↓
OfficeEmployee
    ↓
Administrator / Programmer / Manager
```

Для наследования используется ключевое слово:

```java
extends
```

### Полиморфизм

#### Переопределение (Overriding)

Каждый дочерний класс по-своему реализует методы:

```java
work();
showInfo();
```

#### Перегрузка (Overloading)

Реализованы методы с одинаковыми именами, но разными параметрами.

Например:

```java
assignTask(String task)
assignTask(String task, int priority)
```

## Особенности реализации

### Конструкторы

Для каждого класса реализованы:

- конструктор по умолчанию;
- конструктор с параметрами.

Для вызова конструктора родительского класса используется:

```java
super(...)
```

### Статический счетчик объектов

В классе `Employee` реализован статический счетчик:

```java
private static int employeeCount;
```

Каждый раз при создании нового сотрудника значение счетчика увеличивается.

Это позволяет отслеживать количество созданных объектов.

### Вывод информации

Каждый класс содержит собственную реализацию метода:

```java
showInfo()
```

который выводит полную информацию о сотруднике.

---

## Демонстрация работы программы

В классе `Main` создаются объекты всех типов сотрудников:

- Administrator
- Programmer
- Manager

Для каждого объекта выполняется:

- вывод информации;
- вызов рабочих методов;
- демонстрация полиморфизма;
- демонстрация перегрузки методов.

Также выводится количество созданных сотрудников через статическую переменную.
