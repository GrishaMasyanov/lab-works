# Лабораторная работа №7

## Описание проекта

Данная лабораторная работа посвящена изучению многопоточности в языке Java.

В ходе выполнения работы были рассмотрены основные механизмы создания и управления потоками, синхронизация выполнения задач и совместная работа нескольких потоков с общими данными.

Основное внимание уделено:

- созданию потоков через класс `Thread`;
- выполнению параллельных вычислений;
- синхронизации потоков;
- распределению задач между несколькими исполнителями;
- использованию многопоточности для повышения производительности программы.

---

## Структура проекта

Лабораторная работа состоит из трех независимых заданий:

### ArraySumCalculator

Вычисление суммы элементов массива с использованием нескольких потоков.

### MatrixMaxFinder

Поиск максимального элемента матрицы в многопоточном режиме.

### WarehouseTransfer

Моделирование работы склада и грузчиков с использованием потоков.

---

# Задание 1. Вычисление суммы массива

## Вариант №1

Для решения задачи используются два потока.

Каждый поток вычисляет сумму своей половины массива.

После завершения работы потоков результаты объединяются в главном потоке.

---

## Реализация

Созданы классы:

### SumThread

Отвечает за вычисление суммы заданного диапазона массива.

Каждый объект получает:

- ссылку на массив;
- начальный индекс;
- конечный индекс.

### Main

Создает массив данных и запускает два вычислительных потока.

---

## Алгоритм работы

1. Массив разделяется на две части.
2. Первый поток обрабатывает первую половину массива.
3. Второй поток обрабатывает вторую половину массива.
4. Главный поток ожидает завершения вычислений через:

```java
join()
```

5. Полученные суммы складываются.

---

## Преимущества подхода

- параллельная обработка данных;
- уменьшение времени вычислений для больших массивов;
- демонстрация базовой работы потоков.

---

# Задание 2. Поиск максимального элемента матрицы

## Вариант №1

Для каждой строки матрицы создается отдельный поток.

Каждый поток ищет максимальный элемент своей строки.

После завершения работы всех потоков главный поток определяет общий максимум.

---

## Реализация

Созданы классы:

### MaxFinderThread

Отвечает за поиск максимального значения в одной строке матрицы.

### Main

Создает матрицу, запускает потоки и собирает результаты.

---

## Алгоритм работы

1. Для каждой строки создается поток.
2. Поток вычисляет максимум своей строки.
3. Главный поток ожидает завершения всех вычислений.
4. Производится сравнение найденных значений.
5. Выводится максимальный элемент всей матрицы.

---

## Используемые механизмы

### Thread

Для создания потоков используется наследование:

```java
extends Thread
```

### join()

Для ожидания завершения вычислений используется:

```java
thread.join();
```

# Задание 3. Перенос товаров между складами

## Вариант №1

Для реализации используются отдельные потоки на основе класса:

```java
Thread
```

---

## Постановка задачи

На складе находится набор товаров различного веса.

Работают три грузчика.

Грузчики могут переносить товары одновременно, однако общий вес одной партии не должен превышать:

```text
150 кг
```

После набора партии грузчики отправляются на другой склад для разгрузки.

---

## Реализованные классы

### Product

Описывает товар.

Содержит:

- название товара;
- вес товара.

---

### Warehouse

Хранит список доступных товаров.

Отвечает за выдачу товаров грузчикам.

---

### Loader

Представляет отдельного грузчика.

Каждый грузчик реализован как самостоятельный поток.

Основные обязанности:

- получение товара со склада;
- контроль суммарного веса партии;
- перенос товаров;
- разгрузка на втором складе.

---

### Main

Создает товары, склад и запускает трех грузчиков.

---

## Использование многопоточности

Каждый грузчик работает независимо и параллельно с другими.

Для предотвращения конфликтов при доступе к складу используются механизмы синхронизации.

---

## Синхронизация потоков

Для корректной работы нескольких грузчиков применяется:

```java
synchronized
```

что исключает одновременное изменение общих данных несколькими потоками.

---

## Алгоритм работы

1. На склад добавляются товары.
2. Создаются три грузчика.
3. Каждый грузчик получает товары со склада.
4. Контролируется ограничение в 150 кг на одну перевозку.
5. После набора допустимого веса выполняется транспортировка.
6. После разгрузки процесс продолжается до окончания товаров.

---

## Используемые механизмы многопоточности

### Thread

Создание независимых потоков выполнения.

### start()

Запуск нового потока.

```java
thread.start();
```

### run()

Метод, содержащий выполняемую задачу.

```java
public void run()
```

### join()

Ожидание завершения работы потоков.

```java
thread.join();
```

### synchronized

Защита общих ресурсов от одновременного доступа.

```java
synchronized
```
