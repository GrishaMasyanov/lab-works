# Лабораторная работа №8

## Цель работы

Изучить использование аннотаций, Stream API и средств многопоточного программирования в Java. Получить практические навыки создания приложений для обработки данных с использованием рефлексии, потоков выполнения и функционального подхода к работе с коллекциями.

---

## Теоретическая часть

### Аннотации

Аннотации (Annotations) — это специальные метки, которые добавляют дополнительную информацию к элементам программы: классам, методам, полям и конструкторам. Аннотации могут использоваться компилятором, библиотеками или самим приложением во время выполнения.

Пример:

```java
@Override
public String toString() {
    return "Object";
}
```

В данной работе была создана собственная аннотация `@DataProcessor`, которая используется для пометки методов обработки данных.

---

### Stream API

Stream API предоставляет удобные средства для обработки коллекций данных в функциональном стиле.

Основные операции:

- `filter()` — фильтрация элементов;
- `map()` — преобразование элементов;
- `sorted()` — сортировка;
- `collect()` — сбор результатов в коллекцию.

Пример:

```java
List<String> result = data.stream()
        .filter(word -> word.length() > 5)
        .collect(Collectors.toList());
```

---

### Многопоточность

Для организации параллельной обработки данных использовался пакет `java.util.concurrent`.

Класс `ExecutorService` позволяет создавать пул потоков и выполнять задачи одновременно.

Пример:

```java
ExecutorService executor =
        Executors.newFixedThreadPool(3);

executor.submit(task);

executor.shutdown();
```

## Постановка задачи

Необходимо разработать приложение, которое:

1. Загружает данные из исходного файла.
2. Регистрирует обработчики данных.
3. Выполняет обработку данных с использованием Stream API.
4. Использует собственную аннотацию `@DataProcessor`.
5. Выполняет обработку в нескольких потоках.
6. Сохраняет результат в выходной файл.

## Описание классов

### DataProcessor.java

Содержит пользовательскую аннотацию:

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface DataProcessor {
}
```

Аннотация используется для пометки методов обработки данных.

---

### DataManager.java

Основной класс управления обработкой данных.

Реализует методы:

| Метод | Назначение |
|---------|---------|
| `registerDataProcessor()` | Регистрация обработчиков |
| `loadData()` | Загрузка данных из файла |
| `processData()` | Запуск обработки данных |
| `saveData()` | Сохранение результата |

В классе используется механизм Reflection для поиска методов с аннотацией `@DataProcessor`.

---

### FilterProcessor.java

Выполняет фильтрацию данных.

Оставляет только строки длиной более 5 символов.

Используется Stream API:

```java
.filter(word -> word.length() > 5)
```

---

### UpperCaseProcessor.java

Преобразует строки в верхний регистр.

Используется операция:

```java
.map(String::toUpperCase)
```

---

### SortProcessor.java

Выполняет сортировку данных.

Используется операция:

```java
.sorted()
```

---

### Main.java

Точка входа программы.

Выполняет:

1. Создание объекта DataManager.
2. Регистрацию обработчиков.
3. Загрузку данных.
4. Запуск обработки.
5. Сохранение результата.
