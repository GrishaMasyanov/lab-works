# Лабораторная работа №6

## Описание проекта

Данная лабораторная работа посвящена изучению коллекций, дженериков и итераторов в языке Java.

В ходе выполнения работы были рассмотрены различные типы коллекций из Java Collections Framework, реализован собственный обобщенный стек, а также разработана система учета продаж магазина с использованием коллекции `LinkedHashMap`.

Основное внимание уделено работе с:

- Collection Framework;
- Map;
- Generics;
- Iterator;
- сортировке коллекций;
- обработке данных из файлов.

---

## Структура проекта

Проект состоит из трех независимых заданий:

### TopWords

Поиск наиболее часто встречающихся слов в текстовом файле.

### Stack<T>

Реализация собственного обобщенного стека на основе массива.

### SalesTracker

Система учета продаж магазина.

---

# Задание 1. Анализ текстового файла

## Назначение

Программа считывает текстовый файл и определяет десять наиболее часто встречающихся слов.

Для хранения статистики используется коллекция:

```java
Map<String, Integer>
```

где:

- ключ — слово;
- значение — количество его появлений в тексте.

---

## Основные этапы работы

### Чтение файла

Для чтения данных используется:

```java
Scanner
```

### Подсчет слов

Каждое слово сохраняется в коллекцию `Map`.

При повторном появлении слова счетчик увеличивается.

### Сортировка результатов

Полученные записи преобразуются в список:

```java
List<Map.Entry<String, Integer>>
```

После чего сортируются по убыванию частоты появления.

### Вывод статистики

На экран выводятся:

- 10 самых популярных слов;
- количество их повторений.

---

## Используемые коллекции

```java
HashMap
```

```java
ArrayList
```

# Задание 2. Обобщенный стек

## Назначение

Реализован собственный класс:

```java
Stack<T>
```

использующий механизм дженериков.

Стек работает по принципу:

```text
LIFO
(Last In — First Out)
```

Последний добавленный элемент извлекается первым.

---

## Реализованные методы

### push()

Добавляет элемент в стек.

```java
push(T element)
```

---

### pop()

Удаляет верхний элемент стека и возвращает его.

```java
pop()
```

---

### peek()

Возвращает верхний элемент без удаления.

```java
peek()
```

---

## Использование дженериков

Благодаря параметру типа:

```java
<T>
```

один и тот же класс может работать с различными типами данных:

```java
Stack<Integer>
```

```java
Stack<String>
```

```java
Stack<Double>
```

---

## Особенности реализации

В качестве внутреннего хранилища используется массив объектов.

Размер стека контролируется переменной:

```java
size
```

# Задание 3. Система учета продаж магазина

## Вариант №7

Для хранения информации о продажах используется коллекция:

```java
LinkedHashMap<String, Integer>
```

---

## Назначение программы

Система позволяет:

- регистрировать продажи товаров;
- отображать список проданных товаров;
- вычислять общую сумму продаж;
- определять наиболее популярный товар.

---

## Почему выбран LinkedHashMap

Коллекция `LinkedHashMap` сочетает преимущества:

- быстрого доступа по ключу;
- сохранения порядка добавления элементов.

Это позволяет отображать товары в том порядке, в котором они были зарегистрированы в системе.

---

## Структура данных

Ключ:

```java
Название товара
```

Значение:

```java
Количество продаж
```

Пример хранения:

```text
Ноутбук -> 5
Смартфон -> 8
Наушники -> 3
```

---

## Реализованные возможности

### Добавление продажи

Каждая новая продажа увеличивает счетчик соответствующего товара.

### Вывод списка товаров

Отображаются:

- название товара;
- количество продаж.

### Подсчет общего количества продаж

Вычисляется сумма всех зарегистрированных продаж.

### Поиск самого популярного товара

Определяется товар с максимальным количеством продаж.

---
