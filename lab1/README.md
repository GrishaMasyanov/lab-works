# Лабораторная работа №1

## Описание проекта

В рамках лабораторной работы выполнено знакомство с языком программирования Java, процессом компиляции и запуска программ через JVM.

В работе реализованы три программы:

1. Hello World
2. Поиск простых чисел до 100
3. Проверка строк на палиндром

---

## Структура проекта

Проект включает следующие классы:

### JavaHelloWorldProgram

Базовая программа для демонстрации работы Java-приложения и вывода сообщения в консоль.

### Primes

Программа для поиска простых чисел в диапазоне от 2 до 100.

Основной функционал:

- перебор чисел циклом;
- проверка числа на простоту;
- вывод найденных простых чисел.

### Palindrome

Программа для проверки слов на принадлежность к палиндромам.

Основной функционал:

- разворот строки;
- сравнение исходной и перевёрнутой строк;
- обработка аргументов командной строки.

---

## Реализованные возможности

### Работа с методами

В проекте реализованы пользовательские методы:

- `isPrime(int n)` — определение простого числа;
- `reverseString(String s)` — переворот строки;
- `isPalindrome(String s)` — проверка строки на палиндром.

### Работа с циклами

Использованы циклы:

- `for` для перебора диапазонов чисел;
- `for` для обработки символов строки;
- `for` для обработки аргументов командной строки.

### Работа со строками

Использованы методы класса String:

- `length()`
- `charAt()`
- `equals()`

---

## Особенности реализации

### Поиск простых чисел

Проверка числа выполняется последовательным перебором делителей от 2 до числа `n - 1`.

Если найден делитель без остатка, число считается составным.

### Проверка палиндромов

Алгоритм состоит из двух этапов:

1. Создание перевёрнутой версии строки.
2. Сравнение исходной и полученной строки методом `equals()`.

---

## Пример запуска

### Поиск простых чисел

```bash
java Primes.java
```

### Проверка палиндромов

```bash
java Palindrome madam racecar apple kayak song noon
```
