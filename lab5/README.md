# Лабораторная работа №5

## Описание проекта

Данная лабораторная работа посвящена изучению регулярных выражений (Regular Expressions) в языке Java.

Регулярные выражения используются для поиска, проверки и обработки текстовой информации по заданным шаблонам. В ходе выполнения работы были реализованы программы для поиска данных в тексте, валидации пользовательского ввода и анализа строк.

Для работы использовались классы:

- `Pattern`
- `Matcher`

из пакета:

```java
java.util.regex
```

---

## Структура проекта

Лабораторная работа состоит из пяти независимых заданий:

### NumberFinder

Поиск всех чисел в тексте.

### PasswordValidator

Проверка корректности пароля.

### UppercaseFinder

Поиск случаев, когда после строчной буквы сразу следует заглавная.

### IPAddressValidator

Проверка корректности IPv4-адресов.

### WordFinder

Поиск слов, начинающихся с заданной буквы.

---

## Задание 1. Поиск всех чисел в тексте

### Назначение

Программа выполняет поиск всех числовых значений в заданной строке.

Поддерживаются:

- целые числа;
- дробные числа.

### Используемое регулярное выражение

```regex
\d+(\.\d+)?
```

### Реализованные возможности

- поиск всех совпадений;
- вывод найденных чисел;
- обработка отсутствия совпадений.

### Пример работы

Исходный текст:

```text
The price is 19.99 dollars and delivery costs 5 dollars.
```

Результат:

```text
19.99
5
```

---

## Задание 2. Проверка корректности пароля

### Назначение

Программа проверяет соответствие пароля установленным требованиям безопасности.

### Требования к паролю

Пароль должен:

- содержать только латинские буквы и цифры;
- иметь длину от 8 до 16 символов;
- содержать минимум одну заглавную букву;
- содержать минимум одну цифру.

### Используемое регулярное выражение

```regex
^(?=.*[A-Z])(?=.*\d)[A-Za-z\d]{8,16}$
```

### Проверяемые случаи

Корректные пароли:

```text
Password1
Admin2024
JavaLab55
```

Некорректные пароли:

```text
password
PASSWORD
12345678
pass1
```

## Задание 3. Поиск заглавной буквы после строчной

### Назначение

Программа находит в тексте случаи, когда сразу после строчной буквы следует заглавная без разделителей.

### Используемое регулярное выражение

```regex
[a-z][A-Z]
```

### Реализованные возможности

При обнаружении совпадения найденная последовательность выделяется символами:

```text
!
```

с обеих сторон.

### Пример

Исходный текст:

```text
helloWorld myText exampleString
```

Результат:

```text
hello!oW!orld my!yT!ext example!eS!tring
```

## Задание 4. Проверка корректности IP-адреса

### Назначение

Программа выполняет проверку IPv4-адресов.

### Требования

IP-адрес должен:

- содержать 4 числа;
- числа разделяются точками;
- каждое число находится в диапазоне от 0 до 255.

### Используемое регулярное выражение

```regex
^((25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)\.){3}
(25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)$
```

### Примеры корректных адресов

```text
192.168.1.1
127.0.0.1
255.255.255.255
```

### Примеры некорректных адресов

```text
256.100.50.1
192.168.1
10.10.10.999
```

## Задание 5. Поиск слов по начальной букве

### Назначение

Программа ищет все слова в тексте, начинающиеся с указанной пользователем буквы.

### Используемое регулярное выражение

Для буквы "S":

```regex
\b[Ss]\w*
```

### Реализованные возможности

- поиск всех подходящих слов;
- поддержка верхнего и нижнего регистра;
- вывод списка найденных слов.

### Пример работы

Исходный текст:

```text
Spring Summer Java Student System Programming
```

Результат:

```text
Spring
Summer
Student
System
```

## Используемые возможности Java

### Pattern

Используется для компиляции регулярного выражения.

Пример:

```java
Pattern pattern = Pattern.compile(regex);
```

### Matcher

Используется для поиска совпадений.

Пример:

```java
Matcher matcher = pattern.matcher(text);
```

Основные методы:

```java
find()
matches()
group()
replaceAll()
```
