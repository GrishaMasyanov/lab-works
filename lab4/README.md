# Лабораторная работа №4

## Описание проекта

Данный проект посвящен изучению механизма обработки исключений в языке Java.

В ходе выполнения лабораторной работы были рассмотрены встроенные и пользовательские исключения, а также способы их обработки с использованием конструкций:

- `try`
- `catch`
- `finally`
- `throw`
- `throws`

Проект включает несколько независимых заданий, демонстрирующих обработку различных ошибок во время выполнения программы.

---

## Структура проекта

Лабораторная работа состоит из трех основных частей:

### 1. Обработка исключений при работе с массивами

Класс:

- `ArrayAverage`

Программа вычисляет среднее арифметическое элементов массива и обрабатывает возможные ошибки.

---

### 2. Копирование файлов

Класс:

- `FileCopy`

Программа выполняет копирование содержимого одного файла в другой.

В рамках варианта №1 реализована обработка ошибок, связанных с:

- открытием файлов;
- закрытием файлов;
- отсутствием файлов;
- невозможностью доступа к файлу.

---

### 3. Пользовательские исключения

Классы:

- `CustomEmailFormatException`
- `ExceptionLogger`
- `EmailValidator`
- `Main`

Реализована собственная система обработки исключений для проверки корректности email-адресов.

---

## Задание 1. Работа с массивами

### Назначение

Программа вычисляет среднее арифметическое элементов массива.

### Реализованные проверки

#### Выход за границы массива

Обрабатывается исключение:

```java
ArrayIndexOutOfBoundsException
```

#### Некорректные данные

Обрабатывается исключение:

```java
NumberFormatException
```

или другие ошибки преобразования данных.

### Результат

При возникновении ошибки программа не завершается аварийно, а выводит информативное сообщение пользователю.

---

## Задание 2. Копирование файлов

### Назначение

Программа копирует содержимое исходного файла в целевой файл.

### Реализованные возможности

- открытие файла для чтения;
- создание файла назначения;
- копирование содержимого;
- корректное закрытие потоков.

### Обрабатываемые исключения

```java
FileNotFoundException
```

```java
IOException
```

### Использование блока finally

Для гарантированного закрытия потоков используется блок:

```java
finally
```

который выполняется независимо от возникновения исключения.

## Задание 3. Пользовательские исключения

### Вариант №7

Реализована проверка корректности email-адреса.

Для обработки ошибок создан собственный класс исключения:

```java
CustomEmailFormatException
```

## Реализованные классы

### CustomEmailFormatException

Наследуется от класса:

```java
Exception
```

Используется для обработки ошибок формата электронной почты.

Пример ситуаций возникновения исключения:

- отсутствие символа `@`;
- отсутствие доменной зоны;
- некорректная структура адреса.

---

### EmailValidator

Класс выполняет проверку email-адресов.

Основные функции:

- анализ структуры строки;
- определение корректности формата;
- генерация пользовательского исключения при ошибке.

---

### ExceptionLogger

Отдельный класс для логирования исключений.

Каждое возникшее исключение записывается в текстовый файл.

Сохраняемая информация:

- дата и время возникновения ошибки;
- тип исключения;
- текст сообщения.

---

## Реализованные механизмы обработки исключений

### try-catch

Используется для перехвата и обработки ошибок.

```java
try {
    ...
}
catch(Exception e) {
    ...
}
```

### throw

Применяется для генерации пользовательских исключений.

```java
throw new CustomEmailFormatException(...);
```

### throws

Используется для объявления возможных исключений метода.

```java
public void validateEmail(String email)
        throws CustomEmailFormatException
```

### finally

Используется для выполнения завершающих операций независимо от результата выполнения программы.

## Особенности реализации

### Пользовательские исключения

Создан собственный класс исключения:

```java
CustomEmailFormatException
```

что позволяет более точно определять причину возникновения ошибки.

### Логирование ошибок

Все возникшие исключения автоматически записываются в журнал.

Это позволяет:

- отслеживать ошибки программы;
- анализировать причины сбоев;
- упрощать отладку приложения.

### Работа с файлами

Для чтения и записи используются стандартные средства Java IO.
